## 本地开发

React + Vite。Node.js 版本见 [`.nvmrc`](./.nvmrc)。

```bash
npm ci
npm run dev
```

打开终端显示的地址。

## 检查与构建

```bash
npm run test:runtime
npm run build
npm run preview
```
